# Coordenação entre assistentes

Leia `ler_mudancas(20)` antes de trabalhar. Registre alterações relevantes com `registrar_mudanca`. Cada mudança deve ter um arquivo em `agent_sync/changes/`, e testes/evidências em `agent_sync/tests/`.

Nunca grave senhas, tokens, chaves, strings de conexão ou dados pessoais nesta pasta. Não assuma que um módulo novo está ativo até ele estar integrado, publicado e validado pelo MCP remoto.

Campos mínimos de cada handoff: autor, objetivo, estado, arquivos, interfaces, testes, resultados, limitações, rollback, pendências e responsável seguinte.
